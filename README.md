# Thabani Nkosi — Data Analyst Portfolio

A polished, responsive portfolio built to work **offline** and directly from an extracted ZIP.

## Open the portfolio

1. Extract the ZIP completely.
2. Double-click `index.html`.

No internet connection, CDN, external font, web server, installation or build command is required. All visual styling and interactions are embedded in `index.html`. The downloadable CV remains in `assets/Thabani Nkosi Curriculum Vitae(CV).pdf`.

## Deploy

Upload the extracted folder as-is to GitHub Pages, Netlify, Vercel or any static web host. No build command is required.

## Source files

- `index.html` — standalone portfolio (embedded styles and interactions)
- `styles.css` — readable copy of the embedded styles
- `script.js` — readable copy of the embedded interactions
- `assets/Thabani Nkosi Curriculum Vitae(CV).pdf` — downloadable CV

Project descriptions and career information are based on the supplied CV. Add public repository or case-study links whenever they become available.
